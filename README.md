# Tech Bazaar Computers

Tech Bazaar is a high-performance e-commerce platform custom-built for refurbished and new laptops, desktops, and tech accessories in Kenya. Built with Next.js 16, React 19, Tailwind CSS, and Node.js, featuring direct M-Pesa (Daraja API) payments, real-time inventory management, Cloudinary image hosting, and an admin dashboard.

---

## 🚀 Features

- **Storefront & Catalog**: 67+ real laptop models (HP EliteBook, Dell Latitude, Lenovo ThinkPad/Yoga) with exact KES pricing and high-res photography.
- **M-Pesa STK Push Integration**: Built-in Daraja API integration for direct mobile payments.
- **Responsive & Modern UI**: Sleek obsidian dark/light contrast theme built for maximum performance and engagement.
- **Cart & Checkout**: Real-time persistent state management with full mobile & desktop drawer support.

---

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application live.

---

## 📁 Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Payments**: Safaricom Daraja M-Pesa API
